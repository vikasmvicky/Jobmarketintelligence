## 🎯 Problem Statement

Every fresher entering the data science field asks the same questions:
- What skills should I learn to earn more?
- Which job titles are most in demand?
- Does remote work pay better?
- What salary can I expect at entry level?

This project answers all of them — backed by real data.

---

## 💡 Key Finding

> **Adding Python, Machine Learning, AWS and Spark increases
> a fresher's high salary probability from 36% → 89%.
> A 52.4% improvement from just 4 skills.**

## 🔍 What This Project Does

### 1. 📊 Exploratory Data Analysis
- Top 20 most in-demand skills for data roles
- Top 15 cities for data job opportunities
- Salary distribution across experience levels
- Remote vs office job breakdown
- Most in-demand job titles

### 2. 🤖 Machine Learning — Salary Predictor
- **Algorithm:** Gradient Boosting Classifier
- **Accuracy:** 67.78%
- **Target:** Salary bracket prediction (Low / Mid / High)
- **Explainability:** SHAP feature importance analysis
- **Features used:** 18 features including skills, experience, location

### 3. 💡 Skill Gap Finder
- Enter skills you have
- Get skills you're missing
- See exact salary boost each skill provides
- Backed by ML model predictions

### 4. 🔮 Salary Predictor Tool
- Select your experience level
- Choose your job title
- Tick your skills
- Get instant salary bracket prediction with confidence %

## 🏆 Key Insights From The Data

1. **Skills > Experience** — Python + ML skills impact salary
   MORE than years of experience
2. **Business Analyst > Data Scientist** in demand
   (146 vs 56 postings) — business thinking valued over pure ML
3. **First job = biggest salary jump** — Internship ($56K)
   to Entry Level ($84K) = 50% increase
4. **Remote is rare** — Only 14.4% of data jobs allow
   remote work in 2026
5. **Full-time dominates** — 77% of data roles are full-time
